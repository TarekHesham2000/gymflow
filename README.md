# GymFlow – MVP

نظام جيم جاهز تبيعه لأي جيم: اشتراكات + حجز كلاسات + QR دخول وخروج + **زحمة الجيم لحظياً** (الفكرة الأساسية).
كل جيم = tenant بلونه واسمه، والكود واحد للكل.

## تشغيل
```bash
npm install
npm run seed          # جيم تجريبي "gold" فيه 4 أسابيع بيانات
SUPER_KEY=سر-قوي npm start    # http://localhost:3000
npm test              # 41 اختبار end-to-end
```
المتطلبات: Node 22.5 أو أحدث (بيستخدم SQLite المدمج، مفيش حاجة native تتبني).

## الصفحات
| الرابط | مين بيستخدمه |
|---|---|
| `/g/<slug>` | العضو: الزحمة + توقع الساعات + كلاسات + حجز + كارت QR |
| `/admin/<slug>` | الجيم: نظرة عامة، سكانر دخول/خروج، أعضاء، كلاسات |
| `/super` | انت: إضافة جيم جديد (اسم، لون، سعة، باسورد) بالـ SUPER_KEY |

بيانات الجيم التجريبي: الأدمن `admin123`، العضو موبايل `01000000001` وكود `DEMO22`، وعضو منتهي كود `EXPIR2`.
**غيّر الباسورد والـ SUPER_KEY قبل أي نشر.**

## إزاي الزحمة بتتحسب
- كل مسح QR على الباب = دخول، والمسح التاني = خروج.
- اللي نسي يخرج بيتقفل تلقائياً بعد `stay_hours` (افتراضي 3 ساعات).
- المستوى: أقل من 40% من السعة = هادي، أقل من 75% = متوسط، بعد كده زحمة.
- التوقع لكل ساعة = متوسط نفس اليوم في آخر 4 أسابيع.
- القراءة بالكاميرا بتشتغل على Chrome/Android (BarcodeDetector) ومحتاجة HTTPS. بديلها: سكانر USB أو كتابة الكود.

## الهيكل
```
src/server.js   الـ API والصفحات (Express)
src/crowd.js    حساب الزحمة والتوقع
src/db.js       الجداول (gyms, members, classes, bookings, visits)
src/seed.js     بيانات تجريبية
public/         member.html / admin.html / super.html
test/smoke.js   اختبار شامل
```

## اللي لسه مش موجود (مقصود، للنسخة الجاية)
دفع أونلاين (Paymob/Fawry)، إشعارات واتساب تلقائية، ربط بـ turnstile أو سنسور، تقارير متقدمة، دومين خاص لكل جيم،
تطبيق موبايل تجميعي لكل الجيمات، حاسبة السعرات والخطط الغذائية.
لازم قبل الإنتاج: HTTPS، نسخ احتياطي للـ DB، وقاعدة بيانات أقوى (Postgres) لما العدد يكبر.
